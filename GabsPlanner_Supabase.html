🤖 Lançamento via WhatsApp
Envie mensagens no formato abaixo para o seu número cadastrado.
Lançar despesa:
DESPESA [valor] [categoria] [descrição]

Exemplo:
DESPESA 50 Alimentação Almoço no restaurante

Lançar receita:
RECEITA [valor] [categoria] [descrição]

Exemplo:
RECEITA 1000 Freelance Projeto site institucional
⚠️ A integração com WhatsApp requer configuração adicional via API (Twilio ou Z-API).
